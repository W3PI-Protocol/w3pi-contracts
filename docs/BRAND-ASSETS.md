# W3PI Brand Assets

This folder contains reusable brand assets for GitHub, BscScan, CoinMarketCap, MetaMask-related integrations, Trust Wallet submissions, and website/favicon usage.

## Primary canonical files

- assets/logo.png
- assets/logo.svg
- assets/logo-32.png
- assets/logo-64.png
- assets/logo-128.png
- assets/logo-256.png
- assets/logo-512.png
- assets/logo-1024.png

## Note about the SVG

The included `assets/logo.svg` is an SVG wrapper generated from the PNG source artwork. It is useful as a portable SVG asset link, but it is not a hand-traced true vector recreation.
